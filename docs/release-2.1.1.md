# Mz Hearken 2.1.1 · 焕新重生

> `Mz` = 埋子，`Hearken` = 专注地聆听。

这个版本的主题是**焕新重生**：不新增功能，而是把每天都要碰的那些地方重新做一遍——
图标、播放控制、歌词、列表。目标只有一个：让它看起来像一件正经做出来的东西。

---

## 图标

- 应用图标四角改为圆滑（半径取画布 18%，在 1024 画布上做圆角遮罩后降采样，
  16px 也不出台阶）。任务栏、桌面快捷方式、安装程序、界面徽标全部同步。

## 传输控制

- **播放/暂停键改为圆形**：播放条 36px、正在播放页 60px。
- **进度滑块由长方形改为圆形青铜圆点**（13px），播放条与详情页同一套规格，
  避免两处手感不一致。
- **播放键在栏内居中**：此前三个键在 400px 宽的栏里紧贴左侧，
  播放键中心与栏中心相差 108px，观感上是"歪的"；现在偏差为 0。

## 列表与艺人

- 歌曲缩略图统一为 6px 圆角。
- **多位艺人拆分为独立可点项**：`西原健一郎、Substantial` 不再是一个整体字符串，
  点谁就搜谁、进谁的艺人页。拆分只按「、」与 `feat./ft.` 进行——
  逗号会腰斩 `Leslie Odom, Jr.`，斜杠会拆散 `AC/DC`，宁可少拆也不拆错。

## 歌词

- **创作人名单移出歌词流，固定在歌词区下方常驻显示**：此前它被放在滚动区最顶部，
  一滚动就看不见，且用了近乎透明的淡色。
- 修复**制作信息漏进歌词**：`合声: 周杰伦`、`录音助理: 刘勇志`、`混音工程: …`
  这类"角色词 + 后缀 + 冒号"的行此前会被当成歌词显示。判定规则已改为
  「角色词 + 至多 4 个字符 + 冒号/行尾」，并补充了 `Mixed at …` 一类无冒号的英文写法。
- 修复**打开一首新歌时歌词区顶部出现大片空白**：顶部占位原为框高 42%，
  会把第一句压到框高 42% 处；现改为 64px。同时修正了换歌后的重新定位
  （原逻辑只在"已唱到某一句"时滚动，新歌刚开始时索引为 -1，从不定位）。

## 正在播放页

- 五个功能键（收藏 / 下载 / 队列 / 歌单 / 存封面）**排成一行**，不再换行。
- 文字间距整体收紧，1360×833 的窗口下整栏**一屏可见**，按暂停不必先滚动。

## 安装说明

- 安装包：`MzHearken-2.1.1-win-x64.exe`（文件名不含空格，避免下载链接出现 `%20`）。
- 覆盖安装即可，配置与本地音乐库会保留（2.0.x 起用户数据目录随产品名迁移，迁移只复制、不删除）。
- 尚未进行代码签名，Windows SmartScreen 可能提示"未知发布者"。

## 已知边界

- 窗口高度低于约 820px 时，正在播放页左栏仍需要滚动一次（封面为固定尺寸）；
  后续版本计划在矮窗口下按高度自适应封面。
- 仅提供 Windows x64 安装包。
