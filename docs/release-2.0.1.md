# Mz Hearken 2.0.1

**品牌更名版。功能与 2.0.0 完全一致，但名字换了，并且你的数据一条都没丢。**

---

## 一、新名字

**Mz Hearken** —— `Mz` 是「埋子」的缩写，`Hearken` 是「专注地聆听」。

旧名 MusicHub 是个描述性堆词（music + hub），全网同名产品一大把；`Hearken` 是个生僻的书面词，
英文世界里几乎没有同名播放器 —— 换个说法：**你以后再搜自己的产品名，不会被别人的东西压下去。**

## 二、改了什么（以及**故意没改**什么）

| 位置 | 改动 |
|---|---|
| 安装包 / 开始菜单 / 桌面快捷方式 | `Mz Hearken` |
| 窗口标题、界面品牌字 | `Mz Hearken` |
| 默认下载目录 | `音乐\Mz Hearken`（旧目录里的文件不受影响） |
| 应用 ID（任务栏分组、通知） | `com.mzhearken.app` |
| 安装包文件名 | `MzHearken-2.0.1-win-x64.exe`（**不带空格**，免得发布页 URL 里出现 `%20`） |
| 下载文件内嵌的 ID3 厂商标记 | `Mz Hearken` |

**故意没改**：GitHub 仓库名仍是 `musichub`。因为改仓库名会让历史 release 的下载链接全部失效，
而链接比品牌名更值钱。README / 发布页写新名字就够了。

## 三、新图标

**设计**：白色底 + 墨色衬线字。大写 `MZ`（Georgia Bold，字距收紧）为主，下方 `HEARKEN`
（宽字距、字号约为 MZ 的 1/5）作署名。零渐变、零阴影、零圆角 —— 和界面那套
「大理石暖白 + 青铜」的语言一致。

**三处同源**：界面左上角的徽标、安装包图标、任务栏图标，全部由
`scripts/gen-logo.py` 一份脚本生成，所以不可能出现「界面一个样、任务栏另一个样」。

**顺手修掉一个旧问题**：原来的 `build/icon.ico` 只有 **256×256 一张**，
Windows 任务栏（32/48px）只能把大图缩小，边缘会发糊。现在按尺寸分档生成
**7 档（16/24/32/48/64/128/256）**，每一档都是原生分辨率：

- ≥64px：完整组合（MZ + HEARKEN）
- <64px：只有 MZ 并放大居中 —— 16px 上 HEARKEN 只有 2px 高，硬缩只会糊成一团墨

exe 内嵌图标已用 REA 核验：`icon_groups` 里 7 个图像、全部 32 位色。

## 四、你的数据：一次性迁移（这是这版最关键的部分）

Electron 的用户数据目录由应用名决定。改名之后目录会从

```
%APPDATA%\MusicHub        ← 旧
%APPDATA%\Mz Hearken      ← 新
```

如果什么都不做，你的**收藏、歌单、历史、已存译文（含手工改过的）、音源脚本、AI Key、
下载记录**会"凭空消失"——文件其实还在旧目录里，只是程序不再去那儿找。

所以 `src/main/index.ts` 里加了一段一次性迁移，三条硬规则：

1. **只复制、绝不删除**旧目录 —— 万一新目录出问题，你的原始数据仍然完整
2. **复制失败就退回旧目录继续用** —— 宁可路径难看，也绝不让用户丢数据
3. 搬完写标记文件 `.migrated-from-musichub`，之后不再重复搬、也不会覆盖新目录里已经产生的数据

迁移内容：`*.json`（收藏/歌单/历史/译文/配置）、`sources/`（46 个音源脚本）、
`Local Storage`、`Network`。**跳过** Chromium 的缓存目录（`Cache`/`Code Cache`/`GPUCache` 等，
动辄几百 MB 且毫无迁移价值）。

## 五、安装提醒

因为 exe 名字变了，NSIS 会装到**新目录**：

- 新：`%LOCALAPPDATA%\Programs\Mz Hearken`（或你自选的路径）
- 旧：`%LOCALAPPDATA%\Programs\MusicHub` —— 装好新版后**手动卸载旧的**，不然开始菜单会有两个图标

旧安装卸载时**不要**勾"删除用户数据"，否则 `%APPDATA%\MusicHub` 会被清掉（虽然新版已经复制过一份）。
