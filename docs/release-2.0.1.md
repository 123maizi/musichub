# Mz Hearken 2.0.1

**品牌更名、全新图标，并内置一次性的用户数据迁移。功能与 2.0.0 保持一致。**

---

## 名称：MusicHub → Mz Hearken

- `Mz` —— 作者的署名（埋子）
- `Hearken` —— 专注地聆听（书面语，非描述性堆词）

旧名是一组描述性词汇（music + hub）的组合，同类产品重名较多；新名是一个生僻的书面词，
在同类软件中几乎不存在重名，便于检索与辨识。

## 图标

新版图标为**白底、墨黑与香槟金衬线字标**：大写 `MZ` 为主形，其中嵌一枚音符与一条环绕的声波轨道，
下方是 `MZ HEARKEN` 文字行与声波分隔线。整体不使用渐变、阴影与圆角，以适配浅色与深色两类系统界面。

图标按尺寸分两套画法（图标系统的常规做法）：

| 尺寸 | 内容 | 原因 |
|---|---|---|
| 256 px | 完整作品（字标 + 文字行 + 分隔线） | 大图标位（资源管理器大图、安装包） |
| ≤128 px | 仅字标 | 文字行在 128px 时不足 7px 高，保留只会变成脏点 |

多尺寸 `.ico` 覆盖 16 / 24 / 32 / 48 / 64 / 128 / 256 共 7 档，均为原生分辨率
（不再由单张 256 缩放，任务栏与文件管理器的边缘不再发糊）。
安装包图标、窗口图标、任务栏图标与界面内徽标同源生成。

## 用户数据：一次性迁移

Electron 的用户数据目录由应用名决定。更名后目录变为：

```
旧：%APPDATA%\MusicHub
新：%APPDATA%\Mz Hearken
```

如果仅更名而不处理该目录，收藏、歌单、播放历史、已保存的歌词译文、音源脚本、下载记录
将不再被程序读取（文件仍在旧目录中，但界面上会显示为空）。

因此本版内置一次性迁移，规则如下：

1. **只复制、不删除**旧目录 —— 原始数据始终完整保留
2. 复制失败时**回退到旧目录继续运行** —— 宁可路径保持不变，也不让数据不可用
3. 迁移完成后写入标记文件 `.migrated-from-musichub`，不重复执行，也不会覆盖新目录中已产生的数据

迁移内容包括：`*.json`（收藏 / 歌单 / 历史 / 译文 / 配置）、`sources/`（音源脚本）、
`Local Storage`、`Network`。Chromium 的缓存目录（`Cache`、`Code Cache`、`GPUCache` 等）不迁移，
它们体积大且无迁移价值。

## 其他变更

| 项目 | 变更 |
|---|---|
| 默认下载目录 | `音乐\Mz Hearken`（旧目录中的文件不受影响） |
| 应用 ID | `com.mzhearken.app`（任务栏分组与通知） |
| 安装包文件名 | `MzHearken-2.0.1-win-x64.exe`（不含空格，避免下载链接出现 `%20`） |

| GitHub 仓库名 | **保持不变** —— 更改仓库名会使历史版本的全部下载链接失效 |

## 安装说明

由于可执行文件名变化，安装器会安装到新的目录：

- 新：`%LOCALAPPDATA%\Programs\Mz Hearken`（或安装时自选路径）
- 旧：`%LOCALAPPDATA%\Programs\MusicHub`

安装新版后请手动卸载旧版，避免开始菜单出现两个图标。**卸载旧版时不要勾选「删除用户数据」**，
否则 `%APPDATA%\MusicHub` 会被清除（虽然新版已复制一份，但保留原始数据更稳妥）。
